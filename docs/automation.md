# 기사 자동 생성 시스템 개발 문서

## 📋 프로젝트 배경

**현재 상황**: 기사 생성 앱을 운영 중  
**생성 목표**: 월 150개 기사 (각 분야별 30개)  
**기사 분야**: 스포츠, 사이언스, 비즈니스, 문화, 잡학상식  
**개발 환경**: Python, LangGraph, Tavily Search API

---

## 🚨 핵심 문제: 시간 소모가 너무 크다

### 현재 작업 프로세스 (기사 1개 기준)

1. 주제 직접 선정 (10분)
2. 주제 관련 뉴스 검색 (5분)
3. 적절한 기사 2-3개 URL 찾기 (10분)
4. 각 URL 방문해서 본문 복사 (3개 × 3분 = 9분)
5. 수집한 내용 정리 및 불필요한 부분 제거 (6분)

**→ 기사 1개당 약 40분 소요**  
**→ 하루 5개 = 3시간 20분**  
**→ 월 150개 = 100시간**

### 추가 문제점

- 5개 분야 × 매일 1개씩 = 매일 주제 5개 직접 선정 필요
- 주제 선정이 주관적이고 일관성 없음
- 분야별 적절한 주제 찾기 어려움 (특히 잡학상식)
- 가끔 가십거리 같은 부적절한 주제 선택
- 주제당 2-3개 기사 수동 크롤링 반복
- 광고, 메뉴 등 불필요한 내용 제거 작업

## 🔧 해결책

### 1. 주제당 2-3개 기사 크롤링 자동화

**문제**
- 주제 하나당 2-3개 기사를 수동으로 찾아야 함
- 각 URL 방문해서 본문 일일이 복사
- 광고, 메뉴 등 불필요한 내용 제거 필요
- 150개 주제 × 3개 기사 = 450개 기사 크롤링

**해결책: Tavily Search API**
- 본문 텍스트가 이미 깔끔하게 추출되어 있음
- 광고, 불필요한 요소 자동 제거
- 관련성 높은 기사 자동 선별

**효과**
- 기사 수집 시간: 40분 → 자동
- 본문 추출 및 정리 자동화

**비용**
- 무료: 월 1,000 크레딧
- Tavily Search:
    - Basic Search(`basic`): 한 번 요청 시 **1 크레딧** 사용
    - Advanced Search(`advanced`): 한 번 요청 시 **2 크레딧** 사용
- Tavily Extract:
    - Basic Extract(`basic`): 성공한 URL 5개마다 **1 크레딧** 사용
    - Advanced Extract(`advanced`): 성공한 URL 5개마다 **2 크레딧** 사용

### 2. 5개 분야별 주제 자동 선정

**문제**
- 매일 5개 분야 × 1개 주제 = 5개 주제 직접 선정
- 월 150개 주제를 사람이 찾아야 함
- 분야별 트렌드 파악 어려움

**해결책: AI 자동 주제 선정 시스템 (LangGraph)**

**워크플로우**
```
카테고리 선택 → 트렌드 수집 → 주제 후보 생성 → 품질 필터링 → 주제 검증 → 기사 수집 → 기사 생성
```

**각 단계 역할**
1. **트렌드 수집**: NewsAPI로 한국/일본 분야별 최신 헤드라인 30개 수집
2. **주제 후보 생성**: LLM이 헤드라인 분석 후 5개 주제 후보 제안
3. **품질 필터링**: LLM이 1-10점 평가 후 최고 주제 선택
4. **주제 검증**: 금지 키워드 체크, 미달 시 재생성
5. **기사 수집**: 선정된 주제로 Tavily에서 2-3개 기사 수집 (본문 추출)
6. **기사 생성**: 수집된 기사 기반으로 새 기사 작성

**API 선택**
- **NewsAPI.org**: 한국/일본 뉴스 트렌드 수집 (무료 100 요청/일)
- **Tavily Search**: 선정된 주제의 기사 본문 추출 (무료 1,000 크레딧/월)

**효과**
- 주제 선정 시간: 50분(5개) → 자동
- 분야별 일관된 품질
- 최신 트렌드 자동 반영

---

### 3. 분야별 부적절한 주제 필터링

**문제**
- 가십거리, 논란성 주제가 가끔 선택됨
- 분야별로 원하는 주제 스타일이 다름
- 수동 판단으로 일관성 없음

**해결책: 분야별 필터링 규칙**

| 분야 | ✅ 좋은 주제 | ❌ 나쁜 주제 |
|------|------------|------------|
| **스포츠** | 대회 결과, 기록 경신, 팀/리그 동향 | 선수 사생활, 논란, 폭로 |
| **사이언스** | 연구 결과, 기술 혁신, 과학적 발견 | 검증 안 된 연구, 유사과학 |
| **비즈니스** | 산업 동향, 기업 실적/전략, 경제 정책 | 루머, 추측성 기사 |
| **문화** | 영화제/시상식, 산업 성과, 예술 트렌드 | 방송 발언, 사생활, 가십 |
| **잡학상식** | 과학적 사실, 역사, 심리학, 생활 팁 | 검증 안 된 정보, 미신 |

**구현**
- LLM 프롬프트에 분야별 기준 명시
- 금지 키워드 리스트로 2차 검증
- 기준 미달 시 자동 재생성

**효과**
- 분야별 일관된 품질
- 부적절한 주제 자동 필터링
